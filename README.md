# RLE Compressor (Stack of Books Algorithm)

![Language](https://img.shields.io/badge/language-C-blue.svg)
![Platform](https://img.shields.io/badge/platform-Linux-green.svg)
![License](https://img.shields.io/badge/license-MIT-orange.svg)

Консольная утилита для сжатия и декомпрессии файлов и директорий с использованием алгоритма RLE (Run-Length Encoding), также известного как метод «стопка книг». Проект разработан в рамках <b><i>курсовой работы</i></b> по дисциплине «Основы программирования» (ГУАП, 2024) 🎓.

## 🛠 Установка и сборка

Для сборки проекта требуется компилятор `gcc`.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИКНЕЙМ/rle-compressor.git
   cd rle-compressor
   ```

2. Соберите проект с помощью make:
   ```bash
   make
   ```

После сборки в корне появится исполняемый файл `rle`.

## 🚀 Использование

Формат команды:
```bash
./rle <команда> <путь_к_файлам...>
```

### Команды:
- `compress` — сжать файл(ы) или директорию.
- `decompress` — распаковать архив `.rle`.

### Примеры:

**1. Сжатие одного файла:**
```bash
./rle compress file.txt
# Создаст архив file.rle
```

**2. Сжатие директории:**
```bash
./rle compress my_folder
# Создаст my_folder.rle, содержащий все вложенные файлы
```

**3. Сжатие нескольких файлов в один архив:**
```bash
./rle compress data1.bin data2.log
# Создаст compressed.rle
```

**4. Распаковка:**
```bash
./rle decompress archive.rle
# Восстановит файлы в текущей директории
```

## 🧠 Описание алгоритма

Программа использует вариацию RLE:
1. Читается поток байтов.
2. Подсчитывается количество последовательных одинаковых байтов (до 255).
3. В выходной файл записывается пара: `[количество][байт]`.

Для архивации директорий используется кастомный формат контейнера:
`[Путь файла (256 байт)] [Размер сжатых данных (size_t)] [Сжатые данные]`
